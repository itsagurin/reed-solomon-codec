# results/

Wyniki badań symulacyjnych (generowane przez `simulations/run_experiments.py` i `simulations/plot_results.py`):

- `symbol_errors.csv` - skuteczność korekcji dla e = 1..t+1 błędnych symboli,
- `bsc.csv` - błędy niezależne (BER przed/po RS, FER, retransmisje),
- `burst.csv` - błędy wiązkowe dla L = 8, 16, 32, 64, 128 bitów,
- `*.png` - wykresy do sprawozdania.
